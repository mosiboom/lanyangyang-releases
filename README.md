# 懒羊羊 v2 · 安装包与更新

这个仓库只放**构建产物**，源码不在这里。

## 下载

| 你的 Mac | 用哪个 |
| --- | --- |
| Apple 芯片（M1–M4） | `lanyangyang-<版本>-arm64.zip` |
| Intel 芯片 | `lanyangyang-<版本>-x64.zip` |

解压后把「懒羊羊.app」拖进「应用程序」。

首次打开若提示「无法验证开发者」，右键点「懒羊羊」→ 打开。

## 更新

装上 2.1.0 及以后的版本后，App 会自己检查更新：打开约 12 秒，右下角出现提示，
点「立即更新」即可，不用再手动下载。
